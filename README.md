# GTS302 Sentence Structure Practice

Mock exams for GTS302 Week 14 (Sentence Structure Part 2): compound and complex sentences.

- 7 tests: the official practice test (from the answer key), the slide checkpoint questions, and 5 mock exams
- Exam mode (submit at the end) or practice mode (instant feedback)
- Every answer shows an explanation and the keyword to look for
- Per-topic score breakdown with improvement tips, "retry missed" rounds, and progress saved in the browser

Zero-build static site: open `index.html` or deploy the folder as-is.
